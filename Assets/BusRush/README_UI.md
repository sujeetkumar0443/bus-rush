# Bus Rush – UI (Step 2)

All UI is generated by editor tools, so it can be rebuilt at any time:

| Menu | What it does |
|---|---|
| **Tools › Bus Rush › Build UI (Step 2)** | Regenerates sprites, fonts and every UI prefab, and wires them into Boot / Home / Game. Run after *Run Step 1 Setup* if you ever re-run that. |
| **Tools › Bus Rush › Generate UI Sprites** | Only the procedural sprites and icons (`Art/Sprites/UI`). |
| **Tools › Bus Rush › Capture UI Screenshots** | Plays Boot → Home → every popup → Game → debug popups and saves PNGs to `C:\UnityBuilds\BusRush_Source\unity_shots`. **Resets the editor save** to new-game values first. |

Reference resolution 390×844, Canvas Scaler *Scale With Screen Size*, match 0.5. Every screen and popup has a `SafeArea` child with `SafeAreaFitter`.

## Prefabs (`Prefabs/UI`)

| Prefab | Scene | Script |
|---|---|---|
| `Splash` | Boot | `SplashController` (UI v2: bg, rays, bus, logo, sparkles, loading bar). Preloads Home, then fades to it. Built by **Tools › Bus Rush › Build Splash (R1)**. |
| `HomeScreen` | Home | `HomeScreen`, `LevelPathView`, `CoinText`, `LivesText`. Contains the empty `BannerSlot` (320×50). |
| `GameHUD` | Game | `GameHUD`, `BoosterButtonView` ×3, plus the temporary `DebugPanel (TEMP)` (`DebugOnly` + `DebugPopupPanel`). |
| `UIManager` | Home, Game | Popup canvas (sort order 100) + `UIManager`, reads `PopupCatalog.asset`. |
| `SettingsPopup` | – | Settings from Home; Pause (Home / Restart / Resume) in Game. |
| `DailyRewardPopup` | – | 7 day cards, Claim (real save logic), x2 (ad placeholder). |
| `BoosterPopup` | – | VIP / Arrange / Shuffle tabs, owned count, buy with coins. Empty `Icon3D` image slot for the 3D icon. |
| `LevelCompletePopup` | – | Rays, 3 stars, coin reward, Claim, Next Level, empty `MrecSlot` (300×250). |
| `OutOfSpacePopup` | – | 8 mini bays, +1 Bay for coins or ad placeholder, Give up. |

## Opening popups from code

```csharp
using BusRush.UI;

UIManager.Instance.Open<SettingsPopup>();
UIManager.Instance.Open<DailyRewardPopup>();
UIManager.Instance.Open<BoosterPopup>().Select(BoosterType.Arrange);
UIManager.Instance.Open<OutOfSpacePopup>();

// Level complete with explicit values (otherwise: current level, 3 stars, GameConfig.levelCompleteCoins)
UIManager.Instance.Get<LevelCompletePopup>().Setup(level: 7, starsEarned: 2, coins: 50);
UIManager.Instance.Open<LevelCompletePopup>();

UIManager.Instance.CloseTop();   // or popup.Close(); Android back / Escape also closes the top popup
UIManager.Instance.CloseAll();
```

Useful hooks:

- `UIManager.Instance.BackPressedWithNoPopup` – Game opens the pause menu.
- `OutOfSpacePopup.BayPurchased` – raised after a +1 bay was bought with coins (gameplay subscribes later).
- `UIButton.Clicked` – fires on every button click; hook the click SFX here.
- `SaveSystem.Changed` – coins / lives / boosters / level / settings changed (`CoinText`, `LivesText`, HUD listen to it).

## Adding a popup

1. Create a class deriving from `Popup` (override `OnOpening` / `OnOpened` / `OnClosed`).
2. Build its prefab (root with `CanvasGroup`, `Dim`, `SafeArea/Panel`) – see `UIBuilder.Popups.cs`.
3. Add the prefab to `Prefabs/UI/PopupCatalog.asset`.
